# Render Deployment Guide - Environment Variables Setup

## 🚀 Quick Setup for Render

### Step 1: Add Environment Variables in Render Dashboard

1. Go to your Render dashboard: https://dashboard.render.com
2. Select your **MyPadiCare** service
3. Go to **Environment** tab
4. Click **Add Environment Variable**
5. Add these two variables:

```
GEMINI_API_KEY = your_actual_gemini_api_key_here
ELEVENLABS_API_KEY = your_actual_elevenlabs_api_key_here
```

### Step 2: Configure Build Command

In Render dashboard → **Settings** → **Build Command**:

```bash
chmod +x build.sh && ./build.sh
```

### Step 3: Deploy!

Render will automatically:
- Run the build script
- Inject environment variables into `env-config.js`
- Deploy your app with secure API keys

---

## 📋 How It Works

### Production (Render)
1. Render runs `build.sh` during build
2. Script reads `GEMINI_API_KEY` and `ELEVENLABS_API_KEY` from Render's environment
3. Creates `static/js/env-config.js` with your API keys
4. App loads `env-config.js` → `config.js` reads from `window.ENV`
5. ✅ API keys are secure and never in Git

### Local Development
1. Create `static/js/config.local.js` from template
2. Add your API keys there
3. App loads `config.local.js` → `config.js` reads from `LOCAL_CONFIG`
4. ✅ Works offline without Render

---

## 🔒 Security

✅ **Environment variables** - Stored securely in Render  
✅ **env-config.js gitignored** - Never committed to Git  
✅ **config.local.js gitignored** - Never committed to Git  
✅ **No keys in code** - All keys come from environment  

---

## 📁 File Structure

```
static/js/
├── config.js              # Main config (reads from ENV or LOCAL_CONFIG)
├── env-config.js          # Generated by Render (gitignored) ⚠️
├── config.local.js        # Local dev config (gitignored) ⚠️
└── config.local.js.template  # Template for local setup
```

chmod +x build.sh
./build.sh

## 🐛 Troubleshooting

### "API keys not configured"
- Check Render dashboard → Environment tab
- Verify both `GEMINI_API_KEY` and `ELEVENLABS_API_KEY` are set
- Redeploy after adding variables

### "env-config.js not found"
- Check build command is set: `chmod +x build.sh && ./build.sh`
- Check build logs in Render dashboard
- Verify build.sh has execute permissions

### Local development not working
- Create `config.local.js` from `config.local.js.template`
- Add your API keys there
- Refresh browser

---

## 📝 Notes

- **Never commit** `env-config.js` or `config.local.js` to Git
- Both files are in `.gitignore`
- Render automatically generates `env-config.js` during build
- Local developers use `config.local.js` for development
